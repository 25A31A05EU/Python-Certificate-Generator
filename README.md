🌟 About The Project

Python Certificate Generator is a beginner-friendly automation project that creates colorful and attractive achievement certificates automatically.

Just enter the student name, course name and organization name. The program generates a certificate image with the current date and a unique certificate ID.

✨ Key Features

- 🎨 Modern and colorful certificate design
- 👩‍🎓 Student name input
- 📚 Course name input
- 🏫 Organization name input
- 📅 Automatic date generation
- 🔐 Unique certificate ID
- 🖼️ PNG certificate output
- ⚡ Easy to use

🛠️ Technologies Used

- Python 3
- Pillow Library
- OS Module
- Random Module
- Datetime Module

📂 Project Structure

Python-Certificate-Generator/
│
├── certificate_generator.py
├── requirements.txt

📥 Installation

Install the required library:

pip install Pillow

Or install using requirements:

pip install -r requirements.txt

▶️ How To Run

python certificate_generator.py

Enter the required details:

1. Student Name
2. Course Name
3. Organization Name

Your certificate will be generated automatically!

🎯 Project Objective

To learn Python programming, image processing, file handling and automation through a simple real-world project.

📸 Output

Generated certificate images are saved inside the "certificates" folder.
